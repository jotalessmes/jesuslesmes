# Tarifas propuestas — 16 noviembre 2026

Propuesta inicial para revisar con Jesús antes de publicarla: Landing Esencial desde 390 €; Landing Avanzada desde 790 €; software a medida con presupuesto personalizado. Son precios orientativos, no una afirmación sobre ventas ni una promesa de precio cerrado para cualquier alcance.

## Referencias
- [Vettadev, precios publicados](https://vettadev.com/precios): ejemplo de oferta pública de landing a partir de 450 €, con cuota mensual asociada y condiciones propias.
- [Landinowebs](https://www.landinowebs.com/): referencia de ofertas publicadas de páginas sencillas y corporativas. Cada oferta tiene condiciones y alcances distintos.
- [ProposalForge, tabla de precios de páginas web 2026](https://www.proposalforge.es/es/blog/cuanto-cobrar-pagina-web-2026): sitúa una landing inicial entre 350 € y 700 €. Es una guía comercial, no una medición de transacciones.
- [Nielsen Norman Group, mostrar precios](https://www.nngroup.com/articles/show-price/) y [comparación de opciones](https://www.nngroup.com/articles/comparison-tables/): claridad de precios y diferencias útiles para ayudar a elegir.

## Criterios de presentación
Explicar alcance, número de secciones y rondas de cambios, pago único de las landing, costes externos y mantenimiento por separado. Software con alcance acordado. Evitar afirmar cifras de conversión, ahorros, ventas o popularidad que no estén demostradas. Botones de contacto solamente visuales según la preferencia actual del usuario.

## Antes de publicar
Comprobar si los importes compensan las horas reales, confirmar textos e imágenes aportados por el cliente, disponibilidad para soporte y condiciones fiscales con el profesional correspondiente. Las tarifas propuestas no son definitivas ni implican un régimen fiscal concreto.
